## Инструкция по запуску

### Копируем проект

```bash 
git clone https://github.com/outsider8946/VCD.git
```

### Переходим в папку проекта

```bash
cd VCD
```

### **Вариант 1: Сборка Docker образа**

#### 1. Сборка образа
```bash
docker-compose build
```

#### 2. Запуск образа
```bash
docker-compose up
```


### **Вариант 2: Запуск собраного контейнера из Docker Hub**

#### 1. Скачивание контейнера
```bash
docker pull oustide8946/vcd-app:v1
```

#### 2. Запуск контейнера
```bash
docker run -p 8501:8501 --rm oustide8946/vcd-app:v1 
```


### **Вариант 3: Запуск проекта вручную **

#### 0. Создание виртуального окружения
```bash
conda create --name VCD python=3.10 -y
conda activate VCD
```

#### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

#### 2. Скачивание весов модели
```bash
mkdir -p app/resources
gdown --id "1i8HKhsUjmE_K-0HODZubXArWPIY-Nn_x" -O app/resources/model.pth
```

#### 3. Запуск приложения
```bash
cd app
streamlit run app.py
```

> **🔹 Открыть в браузере:** [http://localhost:8501](http://localhost:8501)


## App

### Возможности веб-сервиса

#### Загрузка изображения
- Поддерживает форматы: PNG
- Создание прямоугольника для локальной кластеризации по двум точкам
- Запсук алгоритма с помощью кнопки "VCD"
- Отчистка результатов работы алгоритма с помощью кнопки "Clear"

#### Работа алогритма 
- Первое изображение отображает выбранную локальную область
- Второе изображение отображает маску, полученную с помощью Unet
- Третье изображение отображает результат выделения стенок сосуда с помощью Canny, примененного к маске Unet
- Четвертое изображение отображает кластеризацию стенок сосуда в локальной области (прямоугольнике) с помощью спектральной кластеризации
